# 验证范围与证据

本页区分协议推导、软件测试、UNO 发送和设备持有人观察。记录日期为 **2026-11-01**，时区 Asia/Singapore。后续实物结果应补充到对应捕获/试验记录，并同步本页的范围。

现有 `ACStateControl` 编译使用 Flash **11034 bytes**、静态 RAM **297 bytes**，目录标识 **`56e058edb903`**。Flash/RAM 数字依赖锁定的 AVR core 1.8.8 与 IRremote 4.7.1。

软件目前 53 项测试通过，涵盖 144 个普通候选编码的唯一性/往返、模式限制、截断与反码错误、单帧 Swing 和混合三帧 Sleep，以及 HTTP 鉴权、防重发和异常恢复。新增定时与预制冷测试覆盖两阶段切换、并发点击、取消、手动接管、2 秒边界（包含发送结果不明的情况）、固件间隔状态解析、离线失败、重启保留与错过不补发。测试不发真实红外；最新远端结果以 [CI](https://github.com/Awes0meE/coolix-ir-controller/actions/workflows/ci.yml) 为准。

## 尚未确认

- 144 个候选组合没有逐个通过 UNO 实物验证；室内机是否支持制热未知。
- LED 四种灯光/提示音组合的循环顺序未知，不提供绝对“灯开/灯关”。
- Turbo、左右 Swing 等虽有原遥控器捕获，并非全部获得 UNO 重放后的独立物理观察。
- Silence 开/关依据图标及交替码对应，重复批次没有逐帧截图标签；保留原始证据边界。
- Follow Me 短按未观察到输出；长按有信号与长鸣，具体功能未知。
- 未测量发射电流、供电裕量、温升、远距离覆盖或长期成功率；不可由单次成功推导。
- 定时开关机和预制冷已通过假串口及隔离浏览器测试；尚未进行真实空调的定时切换或降温效果验证。10 分钟是用户选择的制冷时长，不是室温达标保证。
- 绝对扇叶定位、室温测量和空调状态回传不在现有实现中。
